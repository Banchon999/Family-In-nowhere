# ครอบครัวไร้ถิ่น (Family in Nowhere)

เกมเอาชีวิตรอดแนว RimWorld เน้นเรื่องครอบครัว เล่นบนเว็บ ออกแบบมาสำหรับมือถือเป็นหลัก (เล่นบนคอมได้ด้วย)

คุณจะได้ครอบครัวเล็กๆ 1 ครอบครัว คือพ่อ แม่ และลูกเล็ก 1 คน ที่หลงทางมาอยู่กลางป่า ต้องสร้างบ้าน หาอาหาร ผ่านฤดูหนาว ป้องกันโจร เลี้ยงลูกให้โต แล้วสืบทอดตระกูลไปหลายรุ่น

## วิธีเล่น

- **บนมือถือ/คอม:** เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
- **ติดตั้งเป็นแอป:** ถ้าเปิดผ่านเว็บ (เช่น GitHub Pages) กดเมนูเบราว์เซอร์ > "เพิ่มลงในหน้าจอหลัก" จะเล่นแบบเต็มจอและเล่นออฟไลน์ได้
- เกมบันทึกอัตโนมัติในเครื่องทุกวันในเกม และตอนสลับแอป ย้ายเซฟไปเครื่องอื่นได้ด้วย เมนู > ส่งออกเซฟ

### การควบคุม
| การกระทำ | มือถือ | คอม |
|---|---|---|
| เลื่อนแผนที่ | ลาก 1 นิ้ว | ลากเมาส์ / WASD |
| ซูม | ถ่าง/หุบ 2 นิ้ว | ล้อเมาส์ |
| เลือก | แตะ | คลิก |
| วางสิ่งก่อสร้าง/โซน | เลือกเครื่องมือ แล้วลาก 1 นิ้ว | ลากเมาส์ |
| หยุด/ความเร็ว | ปุ่มขวาบน | Space, 1, 2, 3 |
| ความยาววัน | เลือกตอนเริ่มเกม หรือ เมนู > ตั้งค่า (3/5/8/12 นาทีต่อวัน) | เหมือนกัน |

## ระบบในเกม

- **ครอบครัวและหลายรุ่น:** เด็กโตขึ้นตามเวลา (7 ขวบช่วยงานบ้าน, 13 ปีทำงานได้ทุกอย่าง, 18 ปีเป็นผู้ใหญ่) สามีภรรยาที่นอนเตียงคู่และอารมณ์ดีมีลูกได้ ลูกที่โตจะมีคนมาสู่ขอ ตระกูลสืบต่อไปเรื่อยๆ
- **การดูแลเด็ก:** ทารกต้องมีคนป้อนอาหาร เด็กต้องมีคนเล่นด้วย วิจัย "การศึกษา" แล้วพ่อแม่สอนทักษะให้ลูกได้
- **ความต้องการ:** ความหิว พลังงาน อารมณ์ สุขภาพ ความอบอุ่น ถ้าอารมณ์แย่จะสติแตกไม่ยอมทำงาน
- **นิสัยและทักษะ:** ทุกคนมีนิสัยต่างกัน (ขยัน, ขี้เกียจ, มือเย็น, ทนหนาว ฯลฯ) และทักษะ 9 ด้านที่เก่งขึ้นเมื่อทำงาน
- **ฤดูกาลและอุณหภูมิ:** 4 ฤดู ฤดูหนาวพืชไม่โต ต้องตุนอาหาร มีเสื้อกันหนาว และห้องที่มีกองไฟ/เตาผิง ห้องที่ล้อมกำแพงครบจะมีหลังคาและอุ่นกว่าข้างนอก
- **อาหาร:** ปลูกผัก เก็บผลไม้ป่า ล่าสัตว์ ทำอาหารที่กองไฟ อาหารเน่าได้ถ้าไม่เก็บในที่เย็น
- **งานวิจัย 13 อย่าง:** ข้าวโพด สมุนไพร ก่อหิน เตาหุงต้ม ถนอมอาหาร ตีเหล็ก เลี้ยงสัตว์ การศึกษา ฯลฯ
- **เหตุการณ์สุ่ม:** โจรบุก สัตว์คลั่ง พ่อค้าเร่ ผู้เดินทางขอเข้าร่วม เด็กกำพร้า คนมาสู่ขอ โรคระบาด อากาศหนาวจัด/ร้อนจัด แมลงลงแปลง เกวียนร้าง ฝูงกวางอพยพ
- **การต่อสู้:** เกณฑ์คนไปสู้ ทำอาวุธ (หอก ธนู ดาบ หน้าไม้) สร้างรั้วกำบัง
- **ความสำเร็จและมรดกตระกูล:** ทำความสำเร็จได้แต้มมรดก ใช้ซื้อโบนัสถาวรสำหรับเกมถัดไป
- **เป้าหมายแนะนำ:** สอนเล่นทีละขั้นสำหรับมือใหม่ มีโหมดสงบ (ไม่มีโจร) ให้เลือก

## เผยแพร่บน GitHub Pages (ให้คนอื่นเล่นได้ฟรี)

1. ไปที่ Settings > Pages ของ repo นี้
2. Source เลือก "Deploy from a branch" แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`
3. รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` ส่งให้ใครเล่นก็ได้

## โครงสร้างโค้ด

เขียนด้วย HTML/CSS/JavaScript ล้วน ไม่มี library ไม่ต้อง build

| ไฟล์ | หน้าที่ |
|---|---|
| `js/data.js` | ค่าคงที่และข้อมูลเกม (ไอเทม สิ่งก่อสร้าง งานวิจัย นิสัย ความสำเร็จ) ปรับสมดุลเกมที่นี่ |
| `js/world.js` | สร้างแผนที่ ห้อง/อุณหภูมิ สิ่งของ สิ่งก่อสร้าง พืช |
| `js/path.js` | หาเส้นทาง (A*) |
| `js/pawn.js` | ตัวละคร ความต้องการ อารมณ์ AI เลือกงานและทำงาน ครอบครัว |
| `js/creatures.js` | สัตว์ โจร การต่อสู้ |
| `js/events.js` | เหตุการณ์สุ่ม พ่อค้า ความสำเร็จ มรดก เป้าหมาย |
| `js/sprites.js`, `js/render.js` | กราฟิก pixel art วาดบน canvas แสงกลางคืน หิมะ |
| `js/input.js`, `js/ui.js` | ระบบสัมผัส/เมาส์ และหน้าจอเมนูทั้งหมด |
| `js/save.js`, `js/main.js` | บันทึก/โหลด และ game loop |
